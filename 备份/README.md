# 📚 英语学习网站（本地单机版）

以**视频素材为核心**的轻量化英语自学管理网站。B站/抖音视频双库管理 + 站内播放 + 关键节点标记 + 专属笔记 + 艾宾浩斯遗忘曲线复习提醒，形成「收藏-学习-复盘」的完整闭环。

## ✨ 功能特性

### 视频双库管理
- **每日学习库**：绑定艾宾浩斯复习提醒，核心学习内容池
- **感兴趣视频库**：纯收纳，无提醒无统计，自主安排观看
- 两库之间一键转移，转移时自动处理复习计时（暂停/恢复/从头计算）

### 视频导入与播放
- 粘贴 **B站/抖音** 分享链接或分享文本，自动解析标题/封面/时长（支持 b23.tv 短链）
- B站视频**站内直接播放**（720P mp4 直链，本地代理绕开防盗链），失败自动降级官方嵌入播放
- 抖音视频跳转原平台播放

### 学习工具
- **15 秒快退/快进**：按钮 + 键盘快捷键，精听跟读必备
- **关键节点**：任意时间点添加/编辑/删除/命名节点（如"核心语法""生词段落"），点击一键跳转
- **专属笔记**：每个视频独立纯文本笔记，自动保存 + Ctrl+S
- **进度记忆**：自动保存播放进度，再次打开一键续播

### 艾宾浩斯科学复习（仅每日学习库）
- 标记「已学习」后自动生成复习计划：**第 1 / 3 / 7 / 14 / 21 天** 五个节点
- 进入网站顶部醒目「今日待复习」提醒（含逾期天数标注）
- 完成 5 轮复习后自动标记「复习完成」

### 数据
- 本地存储（localStorage），无账号无云端，完全离线可用
- 支持**导出/导入备份**（JSON 文件）

## 🚀 快速开始

1. 确保本机安装 [Node.js](https://nodejs.org/)（v14+，零依赖无需安装任何包）
2. **双击 `启动.bat`**（或手动运行 `node server.js`）
3. 浏览器自动打开 `http://localhost:8668`，开始使用

> 本地服务用于转发 B站 API/视频流（绕开浏览器 CORS 与防盗链），页面与数据均在本地。

## ⌨️ 快捷键（播放详情页）

| 按键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 15 秒 |
| `↑` / `↓` | 音量 + / - |
| `n` | 在当前时间点添加节点 |
| `[` / `]` | 跳转上一个 / 下一个节点 |
| `f` | 全屏 |
| `m` | 静音 |

## 🛠 技术说明

- 纯原生 HTML/CSS/JS，无框架无构建
- B站视频经代理取 `durl` 音画合一 mp4 直链（免 MSE 合成），`<video>` 原生播放，Range 支持进度拖动
- 数据存 localStorage，schemaVersion 版本化管理
- **跨设备同步**：WebDAV（坚果云等），页脚「数据同步」配置，启动自动同步
- **PWA**：manifest + Service Worker，手机可添加到主屏幕，离线可用
- **云代理**：Cloudflare Worker（`cloudflare-worker.js`）可让在线版 B站视频站内直播

## ☁️ 在线版 B站站内播放（Cloudflare Worker）

在线版（GitHub Pages）默认 B站视频为官方嵌入播放（能看，但 15 秒快进/节点跳转受限）。配置免费的 Cloudflare Worker 云代理后，**在线版/手机端也能站内直接播放，全功能可用**：

1. 注册 [Cloudflare](https://dash.cloudflare.com)（免费）→ Workers & Pages → 创建 Worker
2. 粘贴本仓库 `cloudflare-worker.js` 的全部内容 → 部署
3. 得到地址（形如 `https://your-name.workers.dev`）
4. 网站页脚 →「云代理」→ 填该地址 →「测试连接」→ 保存

免费版 10 万请求/天，个人学习绰绰有余。

## 📱 手机端（PWA）

手机浏览器打开在线网址 → 添加到主屏幕（安卓：菜单⋮→安装应用；iOS：分享→添加到主屏幕），即可像原生 App 一样全屏使用，支持离线查看。

## 📱 跨设备数据同步（WebDAV）

页脚「数据同步」配置坚果云等 WebDAV 服务后，多设备学习数据自动互通（以较新时间戳为准自动合并）。
